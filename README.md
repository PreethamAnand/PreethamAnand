## 📚 ResearchHub AI

**Document-grounded RAG application that answers questions strictly from user-provided documents.**

- Allows users to provide research documents as the knowledge source.
- Processes and divides uploaded information into manageable chunks.
- Generates embeddings for the document content.
- Stores document representations inside a vector database.
- Retrieves relevant document chunks based on the user's query.
- Generates answers using only the retrieved information from the supplied documents.
- Designed to reduce irrelevant information and keep responses grounded in the provided research material.

**Tech Stack:**  
`Python` `FastAPI` `RAG` `Embeddings` `ChromaDB` `Vector Search` `LLMs`

**Status:**  
🟡 Backend/local application — public deployment not currently available.
